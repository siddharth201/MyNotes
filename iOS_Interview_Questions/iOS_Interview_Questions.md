### 🟩 How is a dictionary different from an array?

<details>
<summary><strong>Answer</strong></summary>

A dictionary stores **key–value pairs**, while an array stores **ordered values**.

- Dictionary → Fast lookup by key  
- Array → Ordered collection by index  

```swift
let array = [1, 2, 3]
let dict = ["a": 1, "b": 2]
