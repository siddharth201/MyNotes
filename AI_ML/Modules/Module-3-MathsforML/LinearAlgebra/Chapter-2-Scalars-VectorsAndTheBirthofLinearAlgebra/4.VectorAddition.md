# 📖 Part 10 — Vector Addition

> *"If a vector represents movement, what happens when we perform two movements one after another?"*

---

# 🎯 Why Do We Need Vector Addition?

Imagine you are standing at your home.

You first walk:

* **3 km East**

Then:

* **2 km North**

Question:

Where are you now?

Should we remember two separate movements?

Or can we combine them into one single movement?

This simple question gave birth to **vector addition**.

---

# 🌍 Real World Analogy

Think of Google Maps.

```text
Home
   │
   │ 3 km East
   ▼
Crossroad
   │
   │ 2 km North
   ▼
Office
```

Instead of remembering two separate paths,

Google Maps only needs the **final displacement**.

That is exactly what vector addition computes.

---

# 📌 Mathematical Definition

Two vectors can be added **component-wise**.

If

```math
\mathbf{a}=\begin{bmatrix}a_1 \\ a_2 \end{bmatrix},\qquad\mathbf{b}=\begin{bmatrix}b_1 \\ b_2 \end{bmatrix}
```

then

```math
\boxed{\mathbf{a}+\mathbf{b}=\begin{bmatrix}a_1+b_1 \\ a_2+b_2 \end{bmatrix}}
```

---

## 📚 Understanding Every Symbol

| Symbol       | Meaning               |
| ------------ | --------------------- |
| $\mathbf{a}$ | First Vector          |
| $\mathbf{b}$ | Second Vector         |
| $a_1+b_1$    | Add first components  |
| $a_2+b_2$    | Add second components |

---

# Example

```math
\mathbf{a}=\begin{bmatrix} 2 \\ 3 \end{bmatrix}
```

```math
\mathbf{a}=\begin{bmatrix} 5 \\ 1 \end{bmatrix}
```

Then


```math
\mathbf{a}=\begin{bmatrix} 7 \\ 4 \end{bmatrix}
```

Simple.

Just add corresponding entries.

---

# 📐 Geometry Corner

Imagine arrows.

```text
        ↑
        │
        │
        ●
       /
      /
     /
O────────────►
```

To add vectors,

place the second vector at the tip of the first.

The arrow from the origin to the final point is the **resultant vector**.

This is called the **Head-to-Tail Rule**.

---

# 🧠 Memory Trick

Think:

> **Vector Addition = Follow the Journey**

Instead of asking

> "Where did I walk?"

Ask

> "Where did I finally reach?"

---

# 📖 Part 11 — Vector Subtraction

---

# 🎯 Motivation

Suppose

Today's temperature vector

Minus

Yesterday's temperature vector

What changed?

Subtraction measures **difference**.

---

# Definition

```math
\boxed{\mathbf{a}-\mathbf{b}=\begin{bmatrix}a_1-b_1 \\ a_2-b_2 \end{bmatrix}}
```
---

Example

```math
\begin{bmatrix}7 \\ 5 \end{bmatrix}-\begin{bmatrix}3 \\ 2 \end{bmatrix}=\begin{bmatrix}4 \\ 3\end{bmatrix}
```
---

# 📐 Geometry

Instead of moving forward,

subtraction tells us

> "How much must I move to go from one point to another?"

This idea later becomes **distance**, **error**, and **gradient**.

---

# 🤖 ML Perspective

Prediction Error

=

Prediction Vector

−

Actual Vector

Many ML algorithms repeatedly subtract vectors.

---

# 💻 Python

```python
a=np.array([7,5])
b=np.array([3,2])

print(a-b)
```

Output

```text
[4 3]
```

# 📖 Part 12 — Scalar Multiplication

---

## 🤔 Motivation

Suppose

Your salary doubles.

Every month's salary

×

2

Suppose

Every pixel becomes brighter.

Each pixel

×

1.5

Suppose

Every student's marks increase by 10%.

Each value

×

1.10

We are scaling.

---

# Definition

Multiply every component by the scalar.

$$\boxed{k\begin{bmatrix}x_1\x_2\end{bmatrix}=\begin{bmatrix}kx_1\kx_2\end{bmatrix}}$$

---

Example

$$
2
\begin{bmatrix}
3\
4
\end{bmatrix}
=============

\begin{bmatrix}
6\
8
\end{bmatrix}
$$

---

# 📐 Geometry Corner

Scalar multiplication changes

✅ Length

Sometimes

✅ Direction

---

Positive scalar

Arrow stays same direction.

Negative scalar

Arrow flips.

Example

```text
Positive

--------->

Negative

<---------
```

---

# 🧠 Memory Anchor

> **Scalar Multiplication = Zoom In / Zoom Out**

Imagine zooming a photo.

The shape stays the same.

Only the size changes.

Exactly what scalar multiplication does to vectors.

---

# 🤖 Machine Learning Perspective

Gradient Descent

# 🚀 Preview — Different Types of Norms

So far,

we studied

Euclidean Norm.

But ML uses several norms.

---

## L1 Norm

Distance measured by absolute values.

$$
||x||_1
=======

|x_1|+|x_2|+\cdots
$$

Think

🚕 Taxi driving through city streets.

---

## L2 Norm

Distance measured "as the crow flies."

$$
||x||_2
=======

\sqrt{x_1^2+x_2^2+\cdots}
$$

Think

✈️ Airplane flying directly.

---

## L∞ Norm

Only the maximum component matters.

Useful in optimization and robustness.

---

> 📌 **Note:** We will study norms in depth in the optimization and regularization chapters. For now, just remember that "norm" is the general term for measuring the size of a vector.

# ⚠️ Common Misconceptions

| ❌ Misconception                                     | ✅ Reality                                                                                                |
| --------------------------------------------------- | -------------------------------------------------------------------------------------------------------- |
| Vectors always represent movement                   | In ML, they usually represent data.                                                                      |
| Magnitude is the largest value                      | It is the overall length of the vector.                                                                  |
| Row and column vectors are identical                | They contain the same values but have different orientations and roles in operations.                    |
| A Python list is a vector                           | A list is a programming container; a vector is a mathematical object.                                    |
| Scalar multiplication changes the shape of a vector | It changes its length (and possibly direction if the scalar is negative), not its mathematical identity. |
