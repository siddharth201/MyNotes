# 5.1 — Why Can Cosine Never Be Greater Than 1 or Less Than −1?

## 🎯 Learning Objective

Throughout this chapter we have repeatedly used statements like:

```text
cosθ > 0
cosθ = 0
cosθ < 0
```

and

```text
−1 ≤ cosθ ≤ 1
```

But have you ever wondered:

> **Why is cosine always between −1 and 1?**

Why can't we have

```text
cosθ = 3
```

or

```text
cosθ = -7
```

Is this simply a rule that mathematicians invented?

**No.**

It comes directly from **geometry**.

---

## The Unit Circle Gives the Answer

The easiest way to understand cosine is through the **Unit Circle**.

A **Unit Circle** is simply a circle whose radius is exactly **1**.

When a point moves around this circle, the angle **θ** changes continuously.

The x-coordinate of that point is exactly **cosθ**.

---

## The Most Important Observation

Every point on the unit circle satisfies

```math
x^2+y^2=1
```

Since the circle has radius **1**,

the x-coordinate can never be greater than **1**,

and it can never be less than **−1**.

Therefore,

```math
\boxed{
-1\le x\le1
}
```

But the x-coordinate is precisely **cosθ**.

Hence,

```math
\boxed{
-1\le\cos\theta\le1
}
```

---

## Why Does This Matter?

This simple geometric fact explains every case we studied earlier:

| Angle | x-coordinate |  Cosine |      Dot Product |
| ----- | -----------: | ------: | ---------------: |
| 0°    |            1 | Maximum | Maximum Positive |
| 90°   |            0 |    Zero |             Zero |
| 180°  |           −1 | Minimum | Maximum Negative |

Notice that we are no longer memorizing values—we are **reading them directly from geometry**.

---

## 🤖 Machine Learning Connection

Remember the dot product formula:

```math
\mathbf{x}\cdot\mathbf{y}
=
\|\mathbf{x}\|\,
\|\mathbf{y}\|\,
\cos\theta
```

Since **cosθ** can never exceed **1** or go below **−1**, the dot product is naturally bounded by

```math
-\|\mathbf{x}\|\,\|\mathbf{y}\|
\le
\mathbf{x}\cdot\mathbf{y}
\le
\|\mathbf{x}\|\,\|\mathbf{y}\|
```

This explains why:

* Parallel vectors produce the **largest** possible dot product.
* Opposite vectors produce the **smallest** possible dot product.
* No pair of vectors can exceed these limits.

---

## 🧠 Memory Hook

Think of the unit circle as a **horizontal ruler**.

* Rightmost point → **+1**
* Center → **0**
* Leftmost point → **−1**

Since cosine is simply the **horizontal position** of a point moving around the circle, it can never leave this interval.

> **Cosine doesn't choose the range −1 to 1; geometry forces it to stay there.**

# 🌍 The Unit Circle — Where Cosine Comes From

Most students memorize

```text
cos0°   = 1
cos90°  = 0
cos180° = -1
```

without ever asking

> **Where do these values come from?**

The answer lies in one of the most beautiful objects in mathematics:

> **The Unit Circle**

---

## What is a Unit Circle?

A **Unit Circle** is simply a circle whose radius is exactly **1 unit**.

Imagine placing the circle on the coordinate plane so that its center is at the origin.

```text
              y
              ↑
          ●
      ●       ●
    ●           ●
   ●      O      ●
    ●           ●
      ●       ●
          ●
──────────────→ x
```

Since every point on the circle is exactly **1 unit away** from the origin,

every point satisfies

```math
x^2+y^2=1
```

---

# A Point Moving Around the Circle

Now imagine a point **P** moving around the circumference.

At every position,

it forms an angle **θ** with the positive x-axis.

```
                 y
                 ↑
                 ● P
               /|
             /  |
           /θ   |
         /      |
 O────────────────────→ x
```

As **P** moves,

the angle changes continuously.

---

# The Secret Behind Cosine

Drop a perpendicular from **P** to the x-axis.

```
                 y
                 ↑
                 ● P(x,y)
               /|
             /  |
           /θ   |
         /      |
 O──────●────────────→ x
       cosθ
```

Notice something remarkable.

The horizontal distance from the origin to the foot of the perpendicular is

```text
cosθ
```

In other words,

> **Cosine is simply the horizontal (x) coordinate of a point on the unit circle.**

This single idea explains everything about cosine.

---

# Now Everything Becomes Obvious

Let's move the point around the circle.

### At 0°

```
●──────────────►
```

The point is at

```text
(1,0)
```

Therefore,

```text
cos0° = 1
```

---

### At 90°

```
      ●
      │
      │
```

The point is at

```text
(0,1)
```

Therefore,

```text
cos90° = 0
```

---

### At 180°

```
◄──────────────●
```

The point is at

```text
(-1,0)
```

Therefore,

```text
cos180° = -1
```

---

### At 45°

The point lies somewhere in the first quadrant.

Its x-coordinate is

```text
0.707...
```

Therefore,

```text
cos45°
≈
0.707
```

---

# The Most Important Observation

Look only at the **horizontal position** of the point.

It never goes beyond the right edge of the circle.

```
x = 1
```

It never goes beyond the left edge.

```
x = -1
```

Therefore,

every x-coordinate satisfies

```text
-1 ≤ x ≤ 1
```

But we already discovered that

```text
x = cosθ
```

Hence,

```math
\boxed{
-1
\le
\cos\theta
\le
1
}
```

Notice something beautiful.

We didn't **prove** this using algebra.

We simply **looked at the geometry**.

---

# Why Can't Cosθ Become 2?

Suppose someone claims

```text
cosθ = 2
```

That would mean

the x-coordinate of the point is **2**.

But on a unit circle,

the furthest right point is

```text
(1,0)
```

There is **no point** on the circle whose x-coordinate is **2**.

Therefore,

```text
cosθ = 2
```

is geometrically impossible.

Exactly the same argument explains why

```text
cosθ = -3
```

is impossible.

# 🤖 Machine Learning Connection

Earlier, we proved

```math
\mathbf{x}\cdot\mathbf{y}
=
\|\mathbf{x}\|
\|\mathbf{y}\|
\cos\theta
```

Since

```text
-1 ≤ cosθ ≤ 1
```

the dot product can never exceed

```math
\|\mathbf{x}\|\|\mathbf{y}\|
```

and can never be smaller than

```math
-\|\mathbf{x}\|\|\mathbf{y}\|
```

This is why:

* Parallel vectors produce the **maximum** dot product.
* Perpendicular vectors produce **zero**.
* Opposite vectors produce the **minimum** dot product.
