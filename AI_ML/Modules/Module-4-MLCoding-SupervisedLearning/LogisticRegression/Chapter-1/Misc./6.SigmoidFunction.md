The **Sigmoid Function** (also known as the **logistic function**) is the mathematical bridge that transforms linear regression into a classification model.

---

### 1. The Core Problem It Solves

In standard Linear Regression, the model calculates a linear combination of inputs:


$$z = \mathbf{w}^T \mathbf{x} + b = w_1x_1 + w_2x_2 + \dots + w_n x_n + b$$

The output $z$ is unbounded:


$$z \in (-\infty, +\infty)$$

For binary classification (e.g., classifying an email as Spam ($1$) or Not Spam ($0$)), using raw $z$ causes two major issues:

1. **Invalid Probabilities:** Probabilities must strictly lie in the range $[0, 1]$. A linear equation can output values like $-12.4$ or $+85.0$, which are meaningless as probabilities.
2. **Outlier Sensitivity:** A single extreme data point shifts the linear boundary dramatically, misclassifying valid points.

To fix this, we pass the linear output $z$ through an activation function that squashes any real-valued number into the interval $(0, 1)$.

---

### 2. The Mathematical Definition

The sigmoid function $\sigma(z)$ is defined as:

$$\sigma(z) = \frac{1}{1 + e^{-z}}$$

Where:

* $z = \mathbf{w}^T \mathbf{x} + b$
* $e$ is Euler's number ($\approx 2.71828$)

---

### 3. Key Mathematical Properties

| Value of $z$ | Behavior of $e^{-z}$ | Output $\sigma(z)$ | Interpretation |
| --- | --- | --- | --- |
| $z \to +\infty$ | $e^{-z} \to 0$ | $\sigma(z) \to \frac{1}{1+0} = 1$ | Extremely high confidence in Class 1 |
| $z = 0$ | $e^{0} = 1$ | $\sigma(z) = \frac{1}{1+1} = 0.5$ | Decision boundary (50/50 uncertainty) |
| $z \to -\infty$ | $e^{-z} \to +\infty$ | $\sigma(z) \to \frac{1}{\infty} = 0$ | Extremely high confidence in Class 0 |

#### The S-Shaped Curve

* **Boundedness:** $0 < \sigma(z) < 1$ for all finite $z$.
* **Monotonicity:** The function strictly increases; as $z$ grows larger, $\sigma(z)$ always grows larger.
* **Symmetry:** It is symmetric around $(0, 0.5)$, satisfying $\sigma(-z) = 1 - \sigma(z)$.

---

### 4. Interpretation: Odds and Log-Odds (Logit)

Logistic regression does not just guess an S-curve; it directly models the **log-odds** of the positive class.

1. **Probability ($p$):** Let $p = P(y=1\vert{}\mathbf{x}) = \sigma(z)$.
2. **Odds:** The ratio of the probability of success to the probability of failure:

$$\text{Odds} = \frac{p}{1 - p}$$


3. **Log-Odds (Logit):** Taking the natural logarithm of the odds:

$$\ln\left(\frac{p}{1 - p}\right) = z = \mathbf{w}^T \mathbf{x} + b$$



Inverting this logit formula to solve for $p$ yields the sigmoid function:


$$p = \frac{1}{1 + e^{-z}}$$

Thus, linear regression models the target directly ($y = z$), while logistic regression models the **log-odds** linearly ($\ln(\text{odds}) = z$).

---

### 5. Why Sigmoid is Ideal for Gradient Descent: The Derivative

During model training, weights are updated using backpropagation or gradient descent, which requires computing the derivative of the activation function with respect to $z$.

The derivative of the sigmoid function is remarkably elegant because it can be expressed purely in terms of its own output:

$$\frac{d}{dz}\sigma(z) = \sigma(z)(1 - \sigma(z))$$

#### Quick Derivation:

$$\sigma(z) = (1 + e^{-z})^{-1}$$

$$\frac{d}{dz}\sigma(z) = -1(1 + e^{-z})^{-2} \cdot (-e^{-z}) = \frac{e^{-z}}{(1 + e^{-z})^2}$$

$$\frac{d}{dz}\sigma(z) = \frac{1}{1 + e^{-z}} \cdot \frac{e^{-z}}{1 + e^{-z}} = \sigma(z) \cdot \left(\frac{1 + e^{-z} - 1}{1 + e^{-z}}\right) = \sigma(z)(1 - \sigma(z))$$

Because of this property:

* Computing gradients requires almost **no extra computation**; once the forward pass computes $\hat{y} = \sigma(z)$, the derivative is simply $\hat{y}(1 - \hat{y})$.
* When paired with the **Binary Cross-Entropy (Log Loss)** function, this derivative cancels out terms cleanly, producing a gradient identical in form to linear regression:

$$\frac{\partial J}{\partial \mathbf{w}} = \frac{1}{n} \mathbf{X}^T (\hat{\mathbf{y}} - \mathbf{y})$$



---

### 6. Decision Rule

Once $\hat{y} = \sigma(z)$ is computed, the continuous probability is converted to a discrete binary label using a threshold (commonly $0.5$):

$$\hat{c} = \begin{cases} 1 & \text{if } \sigma(z) \ge 0.5 \quad (\text{equivalent to } z \ge 0) \\ 0 & \text{if } \sigma(z) < 0.5 \quad (\text{equivalent to } z < 0) \end{cases}$$

The hyperplane where $\mathbf{w}^T \mathbf{x} + b = 0$ is the **linear decision boundary**.
