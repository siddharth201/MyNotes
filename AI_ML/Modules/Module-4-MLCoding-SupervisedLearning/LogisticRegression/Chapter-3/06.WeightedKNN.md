The key new idea is:

> In normal KNN, all K neighbors have equal voting importance.

# Weighted KNN

## 1. Why Do We Need Weighted KNN?

First remember **normal KNN**.

Suppose:

```text
K = 4
```

and the nearest neighbors are:

| Neighbor | Class | Distance |
|---|---|---:|
| 1 | Green | 0.1 |
| 2 | Green | 0.1 |
| 3 | Red | 0.5 |
| 4 | Red | 0.5 |

Normal KNN gives **every neighbor one vote**:

```text
Green → 2 votes
Red   → 2 votes
```

We have a **tie**.

But look carefully:

The Green points are **much closer** to our query point.

Shouldn't closer points have more influence?

That's the idea behind **Weighted KNN**.

---

# 2. Core Idea

Weighted KNN says:

> **Closer neighbors should have more influence than farther neighbors.**

So instead of:

```text
Every neighbor → Equal vote
```

we use:

```text
Closer neighbor → Higher weight
Farther neighbor → Lower weight
```

A common weighting formula used in the video is:

**Weight = 1 / Distance**

So:

```text
Small distance → Large weight
Large distance  → Small weight
```

---

# 3. Simple Example

Suppose we have:

```text
Green point → distance = 0.1
Green point → distance = 0.1

Red point   → distance = 0.5
Red point   → distance = 0.5
```

Using:

**Weight = 1 / distance**

### Green points

For distance `0.1`:

```text
Weight = 1 / 0.1
       = 10
```

Each Green point gets:

**Weight = 10**

Total Green weight:

```text
10 + 10 = 20
```

---

### Red points

For distance `0.5`:

```text
Weight = 1 / 0.5
       = 2
```

Each Red point gets:

**Weight = 2**

Total Red weight:

```text
2 + 2 = 4
```

---

# 4. Now Look at the Difference

Normal KNN:

```text
Green → 2 votes
Red   → 2 votes

Result → Tie
```

Weighted KNN:

```text
Green → 20 total weight
Red   → 4 total weight
```

Therefore:

> **Prediction = Green**

Even though both classes have the same number of neighbors, Green wins because its neighbors are much closer.

---

# 5. This is the Main Difference

### Normal KNN

Every neighbor gets equal importance.

```text
Neighbor 1 → 1 vote
Neighbor 2 → 1 vote
Neighbor 3 → 1 vote
Neighbor 4 → 1 vote
```

Distance only determines:

> **Which points get selected.**

---

### Weighted KNN

Distance determines both:

1. **Which points are selected**
2. **How much influence each selected point has**

So:

```text
Normal KNN:

Distance
   ↓
Select K neighbors
   ↓
Equal voting


Weighted KNN:

Distance
   ↓
Select K neighbors
   ↓
Calculate weights
   ↓
Closer → More influence
Farther → Less influence
```

---

# 6. The Formula Used in the Video

The lecture uses:

**Weight = 1 / distance**

Let's make the intuition very clear.

Suppose:

| Distance | Weight |
|---:|---:|
| 0.1 | 10 |
| 0.2 | 5 |
| 0.5 | 2 |
| 1.0 | 1 |
| 2.0 | 0.5 |

Notice the relationship:

> **As distance increases, weight decreases.**

This is exactly what we want.

---

# 7. Why Does `1 / distance` Make Sense?

Imagine two people giving advice.

### Person A

Standing **10 cm** away from you.

### Person B

Standing **10 meters** away.

If we're using physical proximity as a measure of similarity, we'd generally trust the nearby example more.

Similarly in KNN:

> **Closer data point → more similar → more influence**

The `1 / distance` formula captures this relationship.

---

# 8. Another Example

Suppose:

```text
K = 3
```

Nearest neighbors:

| Neighbor | Class | Distance |
|---|---|---:|
| A | Red | 0.1 |
| B | Green | 0.2 |
| C | Green | 0.8 |

### Normal KNN

Votes:

```text
Red   → 1
Green → 2
```

Prediction:

**Green**

---

### Weighted KNN

Calculate weights:

```text
Red:
1 / 0.1 = 10

Green:
1 / 0.2 = 5

Green:
1 / 0.8 = 1.25
```

Total:

```text
Red   → 10
Green → 5 + 1.25 = 6.25
```

Now:

**Weighted KNN → Red**

This is very interesting.

Normal KNN says:

> **Green wins because Green has more neighbors.**

Weighted KNN says:

> **Red wins because the Red neighbor is much closer.**

This demonstrates the main advantage of weighted KNN.

---

# 9. What Is Weighted Voting?

This is the term you should know.

Normal KNN:

> **Majority Voting**

Weighted KNN:

> **Weighted Voting**

Instead of simply counting:

```text
Red   = 1
Green = 2
```

we calculate:

```text
Red   = total weight
Green = total weight
```

The class with the **highest total weight** wins.

---

# 10. Normal KNN vs Weighted KNN

| | Normal KNN | Weighted KNN |
|---|---|---|
| Neighbor importance | Equal | Depends on distance |
| Voting | Equal voting | Weighted voting |
| Closer point | Same vote as others | More influence |
| Farther point | Same vote as others | Less influence |
| Uses distance? | To find neighbors | To find + weight neighbors |

### Mental model

> **Normal KNN asks: "How many neighbors support each class?"**

> **Weighted KNN asks: "How strongly do the neighbors support each class?"**

That's a very useful distinction.

---

# 11. What About a Neighbor Very Close to the Query?

There is an important mathematical issue with:

**Weight = 1 / distance**

What happens if:

```text
distance = 0
```

Then:

```text
1 / 0
```

is undefined.

This happens when the query point is exactly the same as a training point.

In practical implementations, this case needs special handling rather than blindly calculating `1/0`.

You don't need to go deeper into implementation yet; just remember:

> **Distance = 0 needs special handling in inverse-distance weighting.**

---

# 12. Does Weighted KNN Change K?

No.

We still choose:

```text
K = 3
```

or:

```text
K = 5
```

etc.

The difference is **what happens after selecting those K neighbors**.

### Normal KNN

```text
Select K
   ↓
Equal votes
```

### Weighted KNN

```text
Select K
   ↓
Calculate weights
   ↓
Weighted votes
```

So:

> **Weighted KNN is a variation of KNN; K is still a hyperparameter.**

---

# 13. Weighted KNN and Overfitting

This is a useful connection with what you've already learned.

Because closer points receive more influence, Weighted KNN can pay more attention to **local patterns**.

Therefore, the choice of:

- `K`
- distance metric
- weighting scheme

can affect how sensitive the model is to local/noisy observations.

So don't conclude:

> "Weighted KNN always reduces overfitting."

That's not guaranteed.

The weighting scheme changes how neighbors influence the prediction; **K and validation performance still matter**.

---

# 14. Classification vs Regression

Weighted KNN can be used for both.

### Classification

Instead of:

```text
Class A → 3 votes
Class B → 2 votes
```

we calculate:

```text
Class A → total weight
Class B → total weight
```

Highest weight wins.

---

### Regression

Instead of simply averaging the neighbors equally, we can calculate a **weighted average**.

For example:

| Neighbor | Price | Weight |
|---|---:|---:|
| A | 50 | 10 |
| B | 60 | 5 |
| C | 80 | 2 |

A closer neighbor gets more influence on the predicted value.

Conceptually:

> **Weighted KNN Regression = Weighted average of neighbor target values.**

# 16. Why Is Weighted KNN Useful?

Imagine this situation:

```text
Query point

Green → distance 0.1
Green → distance 0.2

Red → distance 1.0
Red → distance 1.1
Red → distance 1.2
```

Normal KNN might say:

```text
Green → 2
Red   → 3

Prediction → Red
```

But perhaps the two Green points are **much more similar** to our query.

Weighted KNN can recognize this:

```text
Green → very high total weight
Red   → lower total weight
```

So Weighted KNN can make the model more sensitive to **local similarity**.

---

# 17. Important: Weighted KNN Still Needs Distance

This connects with the previous lecture.

KNN fundamentally depends on:

> **Distance**

And Weighted KNN depends on it even more.

Because distance now determines:

1. Which neighbors are selected.
2. How much influence each neighbor gets.

Therefore:

> **Feature scaling is particularly important for distance-based KNN methods.**

---

# 18. Interview-Friendly Answer

### What is Weighted KNN?

> **Weighted KNN is a variation of KNN where closer neighbors are given more importance than farther neighbors when making a prediction. A common approach is to assign a weight inversely proportional to distance, such as `w = 1/d`.**

### Difference between KNN and Weighted KNN?

> **Standard KNN gives equal importance to all K neighbors, while Weighted KNN gives greater influence to closer neighbors and less influence to farther neighbors.**

### Why use Weighted KNN?

> **Because two neighbors may not be equally similar to the query point. A closer neighbor may provide stronger evidence than a farther neighbor.**
