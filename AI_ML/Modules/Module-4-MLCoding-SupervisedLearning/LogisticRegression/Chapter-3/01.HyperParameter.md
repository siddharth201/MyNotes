

# What is a Hyperparameter?

A **hyperparameter** is a value that we **choose before training the model** to control how the model learns or behaves.

Simple definition:

> **Hyperparameters are settings chosen by the ML engineer before training; the model does not learn them directly from the training data.**

### Example

Suppose you're training a model.

You might decide:

```text
Learning rate = 0.01
Number of trees = 100
K = 5
```

These are **hyperparameters**.

---

# Hyperparameter vs Parameter

This distinction is very important.

### Parameter

A parameter is **learned by the model from data**.

For example, in Linear Regression:

```text
y = wx + b
```

The model learns:

- `w` → weight
- `b` → bias

These are **parameters**.

---

### Hyperparameter

You choose it **before/during model configuration**.

For example:

```text
K = 5
```

in KNN.

The model doesn't look at the training data and say:

> "Ah, I have discovered that K should be 5."

**You choose K.**

---

# Now specifically: KNN

KNN = **K-Nearest Neighbors**

Suppose we want to classify a new point.

KNN asks:

> "Which K training points are closest to this new point?"

Then it looks at those neighbors and votes.

For example:

```text
K = 3

Nearest neighbors:

Dog
Dog
Cat

Prediction → Dog
```

So:

> **K is a hyperparameter.**

---

# Why is K a Hyperparameter?

Because **we choose K before making predictions**.

For example:

```text
K = 1
K = 3
K = 5
K = 7
```

We can experiment with different values and determine which performs best on validation data.

---

# What happens when K changes?

This is extremely important for understanding KNN.

## K = 1

The model looks at only the **nearest point**.

```text
New point
   ↓
Nearest neighbor
   ↓
Prediction
```

This makes the model very sensitive to individual points/noise.

It can **overfit**.

---

## K = 5

The model looks at the 5 nearest neighbors.

```text
Neighbor 1 → Dog
Neighbor 2 → Dog
Neighbor 3 → Cat
Neighbor 4 → Dog
Neighbor 5 → Cat

Dog = 3
Cat = 2

Prediction → Dog
```

More stable than K=1.

---

## Very large K

Suppose:

```text
K = 100
```

Now the model considers a huge neighborhood.

Local patterns can get ignored.

The model may become too simple and **underfit**.

So there is a trade-off:

```text
Small K                    Large K
   ↓                          ↓
More sensitive             More stable
   ↓                          ↓
Potential overfitting      Potential underfitting
```

---

# KNN Hyperparameters

K is the most important hyperparameter when you're learning basic KNN, but KNN can have other choices too.

### 1. `n_neighbors`

This is **K**.

```text
K = 5
```

Controls how many neighbors participate in the decision.

---

### 2. Distance metric

How do we define "nearest"?

For example:

**Euclidean distance**

\[
d=\sqrt{(x_1-x_2)^2+(y_1-y_2)^2}
\]

But we could use other distance measures.

So the **distance metric** is also a hyperparameter.

---

### 3. Weighting

Suppose K = 5.

Should all five neighbors have equal importance?

Or should closer neighbors have more influence?

For example:

```text
weights = "uniform"

→ every neighbor has equal voting power
```

versus:

```text
weights = "distance"

→ closer neighbors get more influence
```

This is another KNN hyperparameter.

---

# Example in Scikit-learn

You might see:

```python
from sklearn.neighbors import KNeighborsClassifier

model = KNeighborsClassifier(
    n_neighbors=5,
    weights="distance"
)
```

Here:

```text
n_neighbors = 5
weights = "distance"
```

are **hyperparameters**.

The model then uses the training data to make predictions.

---

# How do we choose Hyperparameters?

We generally **don't just guess**.

We try different values and evaluate them using validation data or techniques such as **cross-validation**.

For example:

```text
K = 1  → Accuracy = 82%
K = 3  → Accuracy = 88%
K = 5  → Accuracy = 91%
K = 7  → Accuracy = 90%
K = 9  → Accuracy = 87%
```

We might choose:

```text
K = 5
```

because it performed best during validation.

This process is called:

> **Hyperparameter tuning**

---

# One important point for KNN

KNN is a little different from models like Linear Regression.

In Linear Regression:

```text
Training Data
     ↓
Learn w and b
     ↓
Model
```

But KNN is often called a **lazy learner** because it doesn't learn a conventional set of weights during training.

It largely stores the training examples and uses them when making a prediction.

So for KNN, choices such as:

```text
K
Distance metric
Weighting
```

become especially important.

---

# 🎯 Interview-friendly answer

If interviewer asks:

**"What is a hyperparameter?"**

Say:

> **A hyperparameter is a model configuration or setting that is chosen before training and is not directly learned from the training data. Its value is usually selected using validation or cross-validation.**

If they ask:

**"Give an example in KNN."**

Say:

> **K, or the number of neighbors, is a hyperparameter. We choose K before prediction, and changing K affects the model's complexity and its tendency to overfit or underfit.**

### Your mental model

```text
PARAMETER
→ Model learns it from data

HYPERPARAMETER
→ We choose it before training/tuning
```

For KNN:

```text
K = 5
   ↓
Hyperparameter
   ↓
Controls how many neighbors vote
   ↓
Affects model complexity
   ↓
Tune using validation / cross-validation
```

**One caution:** Don't say *"hyperparameters are never changed during training"* as an absolute rule. More precisely, they are **not learned as ordinary model parameters from the training objective**; we select/tune them outside the model-fitting process.
