


# KNN — K-Nearest Neighbors

KNN stands for **K-Nearest Neighbors**.

It is a **supervised learning algorithm** used for:

- Classification
- Regression

The core idea is very simple:

> **A new data point is likely to have a similar output to the data points that are closest to it.**

In simple words:

> **"Look at the nearest neighbors and let them decide."**

---

# 1. How Does KNN Work?

Suppose we have some already-labeled data points and a **new point** whose class is unknown.

KNN follows these steps:

### Step 1 — Choose K

Choose how many neighbors we want to consider.

For example:

```text
K = 3
```

Here, we will look at the **3 nearest neighbors**.

---

### Step 2 — Calculate Distance

Calculate the distance between the new point and the existing training points.

The videos use **Euclidean Distance**.

For two points:

```text
A = (x₁, y₁)
B = (x₂, y₂)
```

Euclidean distance is:

**Distance = √[(x₂ − x₁)² + (y₂ − y₁)²]**

You can think of it simply as:

> **Straight-line distance between two points.**

---

### Step 3 — Arrange Points by Distance

After calculating the distances, arrange them in **ascending order**:

```text
Smallest distance
       ↓
       ↓
       ↓
Largest distance
```

The closest point comes first.

---

### Step 4 — Select the K Nearest Points

If:

```text
K = 3
```

take the **first 3 points** after sorting.

These are our:

> **3 nearest neighbors**

---

### Step 5 — Make the Prediction

Now what we do depends on whether it is **classification or regression**.

---

# 2. KNN Classification

For classification, KNN uses:

> **Majority Voting**

Suppose:

```text
K = 3
```

and the three nearest neighbors are:

| Neighbor | Class |
|---|---|
| 1 | Class 2 |
| 2 | Class 2 |
| 3 | Class 1 |

Votes:

```text
Class 1 → 1 vote
Class 2 → 2 votes
```

Therefore:

> **Prediction = Class 2**

The class with the most votes wins.

---

# 3. Simple Real-World Example

Imagine we want to classify a fruit as:

- Apple
- Orange

We have a new fruit whose class is unknown.

Suppose its 5 nearest neighbors are:

| Neighbor | Class |
|---|---|
| 1 | Apple |
| 2 | Orange |
| 3 | Apple |
| 4 | Apple |
| 5 | Orange |

Votes:

```text
Apple  → 3
Orange → 2
```

Therefore:

**Prediction = Apple**

This is **majority voting**.

---

# 4. KNN Regression

KNN can also be used for **regression**, where the target is a numerical value.

Instead of voting, we generally take the **average of the target values of the K nearest neighbors**.

Suppose:

```text
K = 3
```

Nearest neighbors have house prices:

```text
₹50 lakh
₹60 lakh
₹70 lakh
```

Prediction:

```text
(50 + 60 + 70) / 3

= 60 lakh
```

Therefore:

> **KNN Classification → Majority Vote**

> **KNN Regression → Average**

This distinction from the video is important.

---

# 5. Complete KNN Algorithm

You can remember the complete process as:

```text
Choose K
   ↓
New data point
   ↓
Calculate distance from training points
   ↓
Sort distances
   ↓
Select K nearest points
   ↓
   ┌───────────────┐
   ↓               ↓
Classification   Regression
   ↓               ↓
Majority Vote    Average
```

This is the core KNN algorithm.

---

# 6. Numerical Example — K = 3

Let's understand the calculation used in the second video.

Suppose our new point is:

```text
P = (2, 5)
```

And one training point is:

```text
A = (3, 6)
```

Euclidean distance:

```text
Distance = √[(3 − 2)² + (6 − 5)²]

         = √[1² + 1²]

         = √2

         ≈ 1.41
```

So:

> Distance between `(2,5)` and `(3,6)` = **1.41**

We do this for **all training points**.

For example, after calculating distances, we might get:

| Point | Class | Distance |
|---|---|---:|
| P1 | Class 2 | 1.41 |
| P2 | Class 1 | 1.41 |
| P3 | Class 2 | 2.00 |
| P4 | Class 1 | 3.00 |
| P5 | Class 2 | 5.00 |

Now:

```text
K = 3
```

So we select:

```text
P1 → Class 2
P2 → Class 1
P3 → Class 2
```

Votes:

```text
Class 1 → 1
Class 2 → 2
```

Therefore:

> **Prediction = Class 2**

---

# 7. Why Do We Need to Sort the Distances?

Because KNN needs the **nearest** points.

Suppose the distances are:

```text
5.00
1.41
3.00
2.00
1.41
```

We can't simply take the first three.

We need to arrange them:

```text
1.41
1.41
2.00
3.00
5.00
```

Then:

```text
K = 3
```

means:

```text
1.41
1.41
2.00
```

These are the three nearest points.

---

# 8. Why is K a Hyperparameter?

Remember our previous discussion about hyperparameters.

**K is a hyperparameter** because we choose it.

For example:

```text
K = 1
K = 3
K = 5
K = 7
```

The model doesn't learn K as a normal model parameter from the training data.

We select/tune K based on validation performance.

---

# 9. Why Does the Choice of K Matter?

This is one of the most important KNN concepts.

## Small K

Suppose:

```text
K = 1
```

Only one neighbor decides the prediction.

If that neighbor happens to be unusual/noisy, it can strongly affect the result.

Therefore:

> **Small K → More sensitive to individual data points → Higher risk of overfitting**

---

## Large K

Suppose:

```text
K = 100
```

Now many points participate in the decision.

One individual point has very little influence.

The prediction becomes smoother, but the model may ignore useful local patterns.

Therefore:

> **Large K → Smoother/simple behavior → Higher risk of underfitting**

---

# 10. Why Does the Video Prefer Odd K?

The second video discusses choosing:

```text
K = 1, 3, 5...
```

rather than:

```text
K = 2, 4, 6...
```

The main reason is to **reduce the possibility of a tie** in binary classification.

For example:

### K = 4

Suppose:

```text
Class A → 2 votes
Class B → 2 votes
```

We have a tie.

---

### K = 5

Suppose:

```text
Class A → 3 votes
Class B → 2 votes
```

There is a clear winner.

So for a simple binary classification problem:

> **Odd K can help avoid ties.**

### Important clarification

Don't memorize:

> "K must always be odd."

That's incorrect.

Odd K is simply a **common practical choice for binary classification** to reduce ties.

For multiclass problems, ties can still happen even with an odd K.

---

# 11. KNN is a Lazy Learner

This is an important concept from the lectures.

KNN is called a:

> **Lazy Learning Algorithm**

Why?

Because KNN doesn't build a conventional mathematical model during training.

It largely **stores the training data**.

When a new point arrives, it does the actual work:

```text
New Point
   ↓
Calculate distances
   ↓
Find nearest neighbors
   ↓
Make prediction
```

So:

### Training

Usually very little computation.

### Prediction

Can require significant computation.

Therefore:

> **KNN has relatively low training cost but potentially high prediction cost.**

---

# 12. Compare KNN with Linear Regression

This comparison helps understand "lazy learning."

### Linear Regression

During training:

```text
Training Data
      ↓
Learn weights + bias
      ↓
Model
```

Then prediction is relatively quick:

```text
New Data
   ↓
Learned Model
   ↓
Prediction
```

---

### KNN

Training:

```text
Training Data
      ↓
Store Data
```

Prediction:

```text
New Data
   ↓
Calculate distances
   ↓
Find neighbors
   ↓
Vote / Average
```

That's why KNN is called **lazy**.

---

# 13. Distance Is Fundamental to KNN

The entire idea of KNN depends on the meaning of **"nearest."**

KNN needs a distance measure.

The videos introduce **Euclidean distance**:

```text
Distance = √[(x₂ − x₁)² + (y₂ − y₁)²]
```

For example:

```text
A = (2, 5)
B = (3, 6)

Distance = √[(3−2)² + (6−5)²]
         = √2
         ≈ 1.41
```

The smaller the distance:

> **The more similar/nearby the points are according to that distance measure.**

---

# 14. An Important Practical Point — Feature Scaling

This is an important consequence of using distance.

Suppose we have:

```text
Age    = 25
Salary = 500000
```

Salary has a much larger numerical scale than Age.

When calculating distance, the salary difference can dominate the calculation.

That can cause KNN to consider points "near" or "far" mainly based on Salary.

Therefore:

> **Feature scaling is generally important for KNN.**

Common techniques include:

- Standardization
- Normalization

We'll cover this properly when your next lectures introduce it.

For now, just remember:

> **KNN is distance-based → feature scale matters.**

# 15. KNN and Overfitting/Underfitting

This connects directly with the topic we just studied.

### Small K

```text
Small K
   ↓
Very local decisions
   ↓
Sensitive to individual points
   ↓
Higher Variance
   ↓
Potential Overfitting
```

### Large K

```text
Large K
   ↓
Many neighbors influence prediction
   ↓
Smoother decisions
   ↓
Higher Bias
   ↓
Potential Underfitting
```

So:

> **K controls how local or smooth the KNN decision is.**

---

# 16. Advantages of KNN

### 1. Simple to understand

The basic idea is intuitive:

> Find neighbors → use them to predict.

### 2. Can handle classification and regression

```text
Classification → Voting
Regression     → Average
```

### 3. No complicated model-training process

It mainly stores the training data.

### 4. Can model complex/local patterns

It doesn't assume a straight-line relationship like simple Linear Regression.

---

# 17. Limitations of KNN

### 1. Prediction can be expensive

For a new point, we may need to calculate distances to many training points.

### 2. Sensitive to feature scaling

Because it depends on distance.

### 3. Sensitive to K

Poor K selection can cause:

- Overfitting
- Underfitting

### 4. Sensitive to irrelevant features

An irrelevant feature can affect the distance and therefore affect which neighbors are selected.

# 18. One Complete Example

Let's put everything together.

Suppose we have a new point:

```text
P = (2, 5)
```

We calculate distances to the training data:

| Point | Class | Distance |
|---|---|---:|
| A | Class 2 | 1.41 |
| B | Class 1 | 1.41 |
| C | Class 2 | 2.00 |
| D | Class 1 | 3.00 |
| E | Class 2 | 5.00 |

We choose:

```text
K = 3
```

Take the three nearest:

```text
A → Class 2
B → Class 1
C → Class 2
```

Voting:

```text
Class 1 → 1
Class 2 → 2
```

Therefore:

> **Prediction = Class 2**

Notice the complete chain:

```text
New Point
   ↓
Calculate Distance
   ↓
Sort by Distance
   ↓
Choose K = 3
   ↓
Take 3 Nearest
   ↓
Majority Voting
   ↓
Class 2
```

# 19. Interview-Friendly Definition

### What is KNN?

> **K-Nearest Neighbors is a supervised learning algorithm that predicts a new data point based on the K closest training examples. For classification, it typically uses majority voting, while for regression, it typically uses the average target value of the nearest neighbors.**

### How does KNN work?

> **First, choose K. For a new data point, calculate its distance from the training points, identify the K nearest neighbors, and then use majority voting for classification or averaging for regression.**

### Why is K called a hyperparameter?

> **Because K is selected by us and is not directly learned as a model parameter from the training data.**

### Why is KNN called a lazy learner?

> **Because it does little model-building during training and performs most of its computation when making predictions.**
