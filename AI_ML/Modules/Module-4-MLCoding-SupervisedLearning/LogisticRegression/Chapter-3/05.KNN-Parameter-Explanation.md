# KNN — Non-Parametric Nature & Working

## 1. KNN is a Non-Parametric Algorithm

This is the main conceptual point of this lecture.

### What does "non-parametric" mean?

In simple terms:

> **A non-parametric model does not assume a fixed mathematical form with a fixed number of learned parameters to represent the data.**

For example, Linear Regression assumes:

```text
y = wx + b
```

and learns:

- `w` → weight
- `b` → bias

These are model parameters.

KNN doesn't learn a similar fixed equation.

Instead, it essentially says:

> **"I'll keep the training examples and use their neighborhood when I need to make a prediction."**

---

# 2. Parametric vs Non-Parametric

| Parametric | Non-Parametric |
|---|---|
| Assumes a fixed model structure | Does not assume a fixed functional form |
| Learns a fixed set of parameters | Relies heavily on training data |
| Example: Linear Regression | Example: KNN |
| Training usually creates a model | KNN mainly stores training examples |

### Simple example

Linear Regression:

```text
Training Data
     ↓
Learn w and b
     ↓
y = wx + b
```

KNN:

```text
Training Data
     ↓
Store training examples
     ↓
Use them when prediction is required
```

---

# 3. Important Clarification: "No Parameters" Doesn't Mean "No Hyperparameters"

The lecturer says something like:

> **There is no parameter to train in KNN.**

This is useful as an introductory statement, but let's make it technically precise.

KNN doesn't learn traditional model parameters such as:

```text
w₁, w₂, ..., b
```

during training.

But KNN **does have hyperparameters**, such as:

```text
K
Distance metric
Weighting method
```

So remember:

> **KNN has no learned parametric model parameters in the usual sense, but it does have hyperparameters that we choose/tune.**

For your current level, the most important one is:

**K = number of neighbors**

---

# 4. What Happens During Training?

This is another important point from the video.

For KNN, the training phase is relatively simple.

Conceptually:

```text
Training Data
     ↓
Store the data
```

There is no process like:

```text
Training Data
     ↓
Gradient Descent
     ↓
Learn weights
     ↓
Create equation
```

as you might see in Linear/Logistic Regression.

So KNN is called a:

> **Lazy Learning Algorithm**

because it postpones most of the work until prediction time.

---

# 5. What Happens During Prediction?

This is where KNN does most of its work.

Suppose a new test point is:

```text
Xq = (x₁, x₂)
```

KNN performs:

```text
New Point Xq
     ↓
Calculate distance from training points
     ↓
Sort / identify nearest points
     ↓
Select K nearest neighbors
     ↓
Majority voting
     ↓
Prediction
```

This is exactly the workflow emphasized in the lecture.

---

# 6. Complete Example from the Lecture

Suppose we have a new point:

```text
Xq = (3, 5)
```

And our training data contains several points.

We calculate the distance from `Xq` to every training point.

For example:

| Point | Class | Distance |
|---|---|---:|
| X1 | Class 2 | 1.41 |
| X2 | Class 1 | 1.41 |
| X3 | Class 2 | 2.00 |
| X4 | Class 1 | 3.00 |
| X5 | Class 2 | 5.00 |
| X6 | Class 3 | 6.48 |

Now suppose:

**K = 3**

We select:

```text
X1 → Class 2
X2 → Class 1
X3 → Class 2
```

Votes:

```text
Class 1 → 1
Class 2 → 2
Class 3 → 0
```

Therefore:

> **Xq belongs to Class 2.**

---

# 7. Why Do We Calculate Distance From Every Training Point?

This is an important part of understanding KNN.

Suppose there are:

**10,000 training points**

and we receive a new point.

KNN needs to know:

> **Which points are closest to this new point?**

So, in the straightforward implementation, it calculates distances between the new point and many/all training points.

Conceptually:

```text
                 Training Data
                 /     |     \
                /      |      \
              X1      X2      X3
               \       |       /
                \      |      /
                 New Point
```

Then it identifies the nearest ones.

This is why KNN can become expensive during prediction when the dataset becomes large.

---

# 8. Why Does KNN Need Sorting?

Suppose calculated distances are:

```text
5.00
1.41
3.00
2.00
1.41
6.48
```

We need the smallest distances.

So we arrange them:

```text
1.41
1.41
2.00
3.00
5.00
6.48
```

If:

**K = 3**

we take:

```text
1.41
1.41
2.00
```

These correspond to our three nearest neighbors.

Then we perform majority voting.

---

# 9. Important Connection: K Controls the Neighborhood

The lecture repeatedly emphasizes that the selection of points depends on **K**.

Think of K as:

> **"How many nearby examples should I listen to?"**

### K = 1

> "I'll listen to only my closest neighbor."

### K = 3

> "I'll listen to my three closest neighbors."

### K = 10

> "I'll listen to my ten closest neighbors."

This is why K changes the behavior of the model.

---

# 10. K and Model Complexity

This connects directly with the Overfitting/Underfitting discussion we just completed.

### Small K

For example:

**K = 1**

The model makes very local decisions.

It can become highly sensitive to individual training examples.

→ **Higher variance**

→ **Possible overfitting**

---

### Large K

For example:

**K = 100**

The model considers a much larger neighborhood.

Individual points have less influence.

→ **Higher bias**

→ **Possible underfitting**

Therefore:

> **K controls how local or smooth the KNN decision is.**

---

# 11. Training vs Testing in KNN

This is probably the most important addition from this video.

| Phase | KNN does |
|---|---|
| Training | Mainly stores training data |
| Prediction/Testing | Calculates distances |
| Prediction/Testing | Finds nearest neighbors |
| Prediction/Testing | Uses K neighbors |
| Prediction/Testing | Makes prediction |

So:

> **KNN has relatively cheap training but potentially expensive prediction.**

This is almost the opposite of what beginners often expect.

---

# 12. Why is KNN Called "Lazy"?

Because it doesn't eagerly build a complex model during training.

It basically says:

> "I'll keep the data now and do the work when you ask me for a prediction."

That's why:

**KNN = Lazy Learner**

You can remember:

> **Lazy during training, busy during prediction.**

---

# 13. Computational Intuition

Suppose:

- `n` = number of training examples
- `d` = number of features

For one new data point, straightforward KNN needs to calculate distances involving the training data.

Roughly:

> **Distance calculation → O(n × d)**

If we then fully sort all `n` distances:

> **Sorting → O(n log n)**

So a straightforward prediction can be roughly:

> **O(n × d + n log n)**

However, this is an implementation-dependent view; optimized nearest-neighbor methods can avoid fully sorting every distance.

For your current notes, the important takeaway is simply:

> **As the training dataset grows, KNN prediction can become computationally expensive.**

---

# 14. Memory Requirement

There is another natural consequence.

Because KNN needs the training data when making predictions, it generally needs to **retain the training dataset**.

So KNN can have a relatively high **memory requirement** compared with a model that compresses the training data into a small set of learned parameters.

Simple mental model:

```text
Linear Regression

Training Data
     ↓
Learn parameters
     ↓
Small model
```

versus:

```text
KNN

Training Data
     ↓
Keep training examples
     ↓
Use them during prediction
```

---

# 15. One Important Correction About "Training"

You may hear:

> "KNN has no training."

That's a little misleading.

A better statement is:

> **KNN has very little traditional model training; it mainly stores the training data and defers most computation until prediction.**

This distinction is useful in interviews.

Don't say:

> ❌ "KNN doesn't have a training phase."

Say:

> ✅ "KNN has minimal training/model-fitting and performs most of its computation during prediction."

# 17. The Three Most Important Ideas from This Video

If you want to keep this video **very small in your revision notes**, remember these three:

### 1. KNN is non-parametric

> It doesn't learn a fixed set of model parameters such as weights and bias to represent the relationship.

### 2. KNN is lazy

> Most of the computational work happens during prediction rather than during training.

### 3. KNN depends on neighborhood

> For a new point, it finds nearby training examples and uses them to make the prediction.

---

# 18. Interview Questions

### Q1. Why is KNN called a non-parametric algorithm?

> Because it does not assume a fixed functional form with a fixed number of learned parameters. It relies directly on the training data and neighborhood structure.

### Q2. Why is KNN called a lazy learner?

> Because it performs minimal model fitting during training and postpones most of the computation until prediction time.

### Q3. What happens during KNN prediction?

> It calculates distances from the query point to the training examples, identifies the K nearest neighbors, and uses majority voting for classification or averaging for regression.

### Q4. Why can KNN prediction be expensive?

> Because it may need to calculate distances to many training examples for every new prediction.

### Q5. Does KNN have hyperparameters?

> Yes. K is the main hyperparameter, and other choices can include the distance metric and weighting method.
