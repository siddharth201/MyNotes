An **outlier** is a data point that differs significantly from the remaining observations in a dataset. It lies an abnormal distance away from other values in a random sample of a population.

---

### Why Do Outliers Occur?

1. **Measurement or Data Entry Errors:** Human typos (e.g., entering an age as `250` instead of `25`) or faulty sensor readings.
2. **Natural Variations (True Anomalies):** Legitimate, rare real-world extremes (e.g., a customer making a $1,000,000 purchase during a holiday sale or a high-net-worth individual in an income study).
3. **Sampling or Processing Errors:** Mixing data from different distributions or errors occurring during data extraction/transformation.

---

### How Outliers Impact Machine Learning Models

* **High Sensitivity (Heavily Impacted):**
* **Linear & Logistic Regression:** Outliers pull the regression line or decision boundary toward themselves to minimize squared/log loss, distorting coefficients.
* **Distance-based algorithms (KNN, K-Means, SVM with RBF kernel):** Calculate Euclidean or Manhattan distances, which are inflated by extreme values.
* **Neural Networks:** Large input values produce explosive gradient updates, destabilizing optimization.


* **Low Sensitivity (Robust):**
* **Tree-based algorithms (Decision Trees, Random Forest, XGBoost):** Make decisions based on rank/split thresholds, meaning an extreme value at the high or low end does not distort intermediate cutoffs.



---

### Common Detection Methods

#### 1. IQR Method (Box Plot Rule)

Best for **skewed distributions**.

* Compute the Interquartile Range: $\text{IQR} = Q_3 - Q_1$.
* Define bounds:

$$\text{Lower Bound} = Q_1 - 1.5 \times \text{IQR}$$


$$\text{Upper Bound} = Q_3 + 1.5 \times \text{IQR}$$


* Any value falling outside these bounds is flagged as an outlier.

#### 2. Z-Score Method

Best for **normally distributed (Gaussian)** data.

* Calculate standard deviations away from the mean:

$$Z = \frac{x - \mu}{\sigma}$$


* A standard cutoff is $\vert{}Z\vert{} > 3$ (data points more than 3 standard deviations from the mean).

#### 3. Visual Inspection

* **Box plots:** Direct visualization of the 5-number summary and IQR outliers.
* **Scatter plots:** Useful for bivariate outliers (points that appear normal in each feature separately, but anomalous in combination).

---

### How to Handle Outliers

1. **Remove / Trim:** Appropriate if the outliers are verified data-entry or measurement errors.
2. **Cap / Winsorize:** Replace values beyond boundaries with the boundary values themselves (e.g., set any value above the 99th percentile to the 99th percentile).
3. **Transform:** Apply a mathematical transformation (like $\log(x)$ or square root) to compress the long tail of right-skewed distributions.
4. **Keep:** If the outlier represents true rare behavior (e.g., fraud detection), removing it deletes the exact signal the model needs to learn.
