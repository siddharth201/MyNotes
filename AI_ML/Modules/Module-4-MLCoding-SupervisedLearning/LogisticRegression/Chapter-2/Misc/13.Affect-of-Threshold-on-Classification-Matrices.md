# Effect of Threshold on Precision and Recall

## 1. First: What is Threshold?

Logistic Regression gives a **probability**, for example:

```text
Person A → 0.95
Person B → 0.85
Person C → 0.75
Person D → 0.60
Person E → 0.40
```

But ultimately we need:

```text
Disease = 1
No Disease = 0
```

So we need a **threshold**.

The default threshold is usually:

**0.5**

Meaning:

```text
Probability >= 0.5 → Predict 1
Probability < 0.5  → Predict 0
```

# 5. What happened to Precision?

Precision:

**TP / (TP + FP)**

= 2 / (2 + 0)

= **100%**

Previously:

**80%**

Now:

**100%**

### Why?

Because we became **very strict** about calling someone "Disease".

We only call someone positive when probability is at least 0.8.

Therefore, we eliminated the False Positive:

```text
F: 0.70

At threshold 0.5 → Disease ❌
At threshold 0.8 → No Disease ✅
```

So:

**FP decreased → Precision increased.**

---

# 6. What happened to Recall?

Recall:

**TP / (TP + FN)**

= 2 / (2 + 3)

= **40%**

Previously:

**80%**

Now:

**40%**

Why?

Because we missed more actual disease cases.

For example:

```text
C → 0.75
D → 0.60
E → 0.40
```

All three actually have disease.

But our new threshold is 0.8.

So we reject all three.

They become:

```text
C: 1 → 0 = FN
D: 1 → 0 = FN
E: 1 → 0 = FN
```

Therefore:

**FN increased → Recall decreased.**

# 8. What if we decrease the threshold?

Now imagine:

**Threshold = 0.3**

Our model becomes more willing to say:

> "Disease!"

Even a probability of 0.3 is enough.

So we will catch more actual disease cases.

Therefore:

**FN tends to decrease → Recall increases.**

But we will also incorrectly classify more healthy people as diseased.

Therefore:

**FP tends to increase → Precision decreases.**

So:

```text
Decrease Threshold
        ↓
More Positive predictions
        ↓
   ┌────┴─────┐
   ↓          ↓
  FN ↓       FP ↑
   ↓          ↓
Recall ↑   Precision ↓
```

# 9. The easiest way to remember it

Think about the threshold as a **strictness level**.

### Low threshold = Less strict

```text
"Give me more people who might have disease."
```

Result:

**Recall ↑**

But:

**Precision ↓**

---

### High threshold = More strict

```text
"Only tell me disease when you're really confident."
```

Result:

**Precision ↑**

But:

**Recall ↓**

---

# 10. Connect this to your previous lesson

Remember:

### Recall

> **Don't miss actual Positives.**

So if Recall is important, we generally don't want a very high threshold.

Example:

**Life/death medical screening**

We may prefer a lower threshold to catch more potentially sick patients.

---

### Precision

> **When I say Positive, I want to be correct.**

So if Precision is important, we may use a higher threshold.

Example:

Suppose a Positive prediction triggers an expensive or invasive procedure.

We may want to be more confident before predicting Positive.

---

# 11. Very important: Threshold does NOT retrain the model

This is an important concept.

Changing:

```text
Threshold = 0.5
```

to:

```text
Threshold = 0.8
```

does **not** change the Logistic Regression model itself.

The model still produces the same probabilities:

```text
A → 0.95
B → 0.85
C → 0.75
...
```

We are only changing the rule that converts probability into a class.

```text
Model
 ↓
Probability
 ↓
Threshold
 ↓
Class
```

So:

> **Threshold changes classification decisions, not the underlying probability predictions.**

---

# 12. One very important correction

Don't memorize this as an absolute mathematical law:

> ❌ "Increasing threshold ALWAYS increases Precision and ALWAYS decreases Recall."

The safer statement is:

> **As the threshold increases, Precision generally increases while Recall generally decreases.**

For a particular dataset, there can be tied probabilities or unusual behavior at individual threshold values.

But the overall trade-off is exactly what the video is teaching.

# 🎯 Final Mental Model

Imagine the model gives:

```text
A → 0.95
B → 0.85
C → 0.75
D → 0.60
E → 0.40
```

### Threshold = 0.5

A, B, C, D → Positive

### Threshold = 0.8

Only A, B → Positive

So increasing the threshold means:

> **"I will only call something Positive when I'm more confident."**

Therefore:

**Fewer false alarms → Precision increases**

but:

**More actual Positives get missed → Recall decreases**

### The one line to remember:

> **High threshold → High Precision, Low Recall.**  
> **Low threshold → Low Precision, High Recall.**

This is the exact connection between **Threshold → FP/FN → Precision/Recall** that the video is trying to establish.
