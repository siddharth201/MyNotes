This code performs **feature scaling** (specifically **Standardization** or **Z-score normalization**) across your train, validation, and test datasets.

---

### What `StandardScaler` Does Mathematically

It transforms each numerical feature so that:

* **Mean ($\mu$) = 0**
* **Standard Deviation ($\sigma$) = 1**

For every feature value $x$:

$$z = \frac{x - \mu}{\sigma}$$

This brings all features to the same scale (e.g., preventing a feature like `Annual Salary` in tens of thousands from dominating a feature like `Age` in tens).

---

### Why `fit_transform` on Train, but only `transform` on Test/Validation?

This is the most critical pattern in machine learning preprocessing:

#### 1. `scaler.fit_transform(X_train)`

* **`fit`**: Calculates and stores the **mean ($\mu$)** and **standard deviation ($\sigma$)** using **only** the training set.
* **`transform`**: Applies the formula $z = \frac{x - \mu_{\text{train}}}{\sigma_{\text{train}}}$ to rescale `X_train`.

#### 2. `scaler.transform(X_test)` and `scaler.transform(X_valid)`

* **`transform` only**: Uses the **already learned** $\mu_{\text{train}}$ and $\sigma_{\text{train}}$ from the training set to scale the test and validation sets.
* It does **not** recalculate mean or standard deviation on the test/validation data.

---

### Why Not `fit` on Test or Validation?

Doing `scaler.fit_transform(X_test)` causes **Data Leakage**:

* The test and validation sets are meant to simulate **future, unseen data** in a real-world production environment.
* In production, you might receive a single customer record to predict churn. You cannot compute a mean or standard deviation on a single row.
* Calculating statistics from the test set leaks distribution information from the evaluation data into your preprocessing pipeline, leading to unrealistically optimistic performance estimates.

---

### Key Takeaway

| Dataset | Method Used | Purpose |
| --- | --- | --- |
| **`X_train`** | `fit_transform()` | Learn parameters ($\mu, \sigma$) **and** scale the training data. |
| **`X_valid`** | `transform()` | Scale validation data using training parameters only. |
| **`X_test`** | `transform()` | Scale test data using training parameters only. |

*(Note: `StandardScaler` outputs a NumPy array by default, losing DataFrame column names unless converted back or configured with `scaler.set_output(transform="pandas")`.)*
