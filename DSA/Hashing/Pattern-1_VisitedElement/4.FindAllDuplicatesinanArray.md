>Given an integer array, return all duplicate elements.

### Example

#### Input
```swift
[4,7,2,9,7,4,5]
```

#### Output
```swift
[7,4]

Because

both

7

and

4

appear more than once.
```

### Solution
```swift
func findDuplicates(_ nums: [Int]) -> [Int] {

    var visited = Set<Int>()
    var reported = Set<Int>()
    var result: [Int] = []

    for num in nums {

        if visited.contains(num) {

            if !reported.contains(num) {
                result.append(num)
                reported.insert(num)
            }

        } else {
            visited.insert(num)
        }
    }

    return result
}
```  

**Complexity**  
**Time:** `O(n)`  
**Space:** `O(n)`
