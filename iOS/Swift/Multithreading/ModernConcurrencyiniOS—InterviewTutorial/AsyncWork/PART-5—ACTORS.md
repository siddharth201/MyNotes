<details>
<summary><b>Q24. What problem do Actors solve?</b></summary>

Imagine:

```swift
final class Counter {

    var value = 0

    func increment() {
        value += 1
    }
}
```

And:
Task {
    counter.increment()
}

Task {
    counter.increment()
}

Task {
    counter.increment()
}

Multiple concurrent accesses can race on shared mutable state.

Swift's actor model protects mutable state through isolation and serialized access.
