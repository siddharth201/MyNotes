Let's solve it step by step.

---

## Given

* **a** and **b** are unit vectors.

Therefore:

```text
|a| = 1
|b| = 1
```

Let the angle between them be ( \theta ).

Then:

[
a \cdot b = |a||b|\cos\theta
]

Since both are unit vectors:

[
a \cdot b = \cos\theta
]

---

## Given vectors

[
c = a + 2b
]

[
d = 5a - 4b
]

and they are perpendicular.

Perpendicular vectors satisfy:

[
c \cdot d = 0
]

---

### Compute dot product

[
(a+2b)\cdot(5a-4b)=0
]

Expand:

[
5(a\cdot a)
-4(a\cdot b)
+10(b\cdot a)
-8(b\cdot b)
=0
]

Since:

[
a\cdot a = 1
]

[
b\cdot b = 1
]

[
a\cdot b = b\cdot a = \cos\theta
]

Substitute:

[
5 -4\cos\theta +10\cos\theta -8 = 0
]

[
5 +6\cos\theta -8 = 0
]

[
6\cos\theta -3 = 0
]

[
6\cos\theta = 3
]

[
\cos\theta = \frac12
]

---

## Find the angle

We know:

[
\cos\theta=\frac12
]

Using the unit circle:

[
\theta = \cos^{-1}\left(\frac12\right)
]

[
\theta = \frac{\pi}{3}
]

---

## Answer

[
\boxed{\frac{\pi}{3}}
]

or approximately

```text
1.0472 radians
```

### Quick Interview Trick

Whenever you see:

* Unit vectors
* Angle between vectors

Immediately remember:

[
a \cdot b = \cos\theta
]

because (|a|=|b|=1), which makes the algebra much simpler.
