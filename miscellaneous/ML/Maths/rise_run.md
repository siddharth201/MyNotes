**Rise / Run** is the most intuitive way to understand the slope of a line.

It tells:

> How much the line goes **up or down** compared to how much it goes **left or right**.

---

# 1. Meaning of Terms

## Rise = Vertical change (Y direction)

How much height changes.

[
\text{Rise} = \Delta y = y_2 - y_1
]

* Positive rise → goes upward
* Negative rise → goes downward

---

## Run = Horizontal change (X direction)

How much horizontal distance changes.

[
\text{Run} = \Delta x = x_2 - x_1
]

* Positive run → right side
* Negative run → left side

---

# 2. Slope Formula

m=\frac{rise}{run}=\frac{\Delta y}{\Delta x}

This tells steepness.

---

# 3. Example

Take two points:

* (1,2)
* (4,8)

Rise:

8-2=6

Run:

4-1=3

Slope:

m=\frac{6}{3}=2

Meaning:

> For every 1 step right, line rises 2 steps up.

---

# 4. Why Called Rise / Run?

Imagine walking on a hill:

* **Run** = how far you walk forward
* **Rise** = how much height you gained

If hill rises fast → steep slope.

---

# 5. Different Cases

## Positive slope

Rise positive, run positive.

Line goes upward ↗

## Negative slope

Rise negative, run positive.

Line goes downward ↘

## Zero slope

Rise = 0

Flat line.

## Undefined slope

Run = 0

Vertical line.

---

# 6. Why Important in ML?

Slope means rate of change.

Examples:

* Hours studied vs marks
* House size vs price
* Ad spend vs sales

If slope = 5:

> Every extra 1 unit input increases output by 5.

That is core idea of linear regression.

---

# 7. Why tanθ = rise/run

For a line making angle θ:

\tan\theta=\frac{opposite}{adjacent}=\frac{rise}{run}

So slope = tanθ.

---

# 8. Ultimate Intuition

If someone says slope = 3:

Think:

> move right 1 → go up 3

If slope = -2:

> move right 1 → go down 2

---

# 9. One Hidden Insight

Slope is not about total height.
It is about **change compared to movement**.

That’s why rise/run is powerful.
